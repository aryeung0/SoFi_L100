# SoFi Finance AI Champions — Level 100 Hands-On Guide

A self-service Snowflake Hands-On Lab. Run one setup script, then explore a governed finance dataset using two AI-powered tools: **CoCo** (Cortex Code) for hands-on SQL exploration, and **CoWork** for conversational, chart-ready answers.

## What You'll Build

One script sets up a small but complete Snowflake-native finance analytics environment:

- A **data foundation** — 6 governed tables covering invoices, vendors, loans, products, and competitor earnings
- An **intelligence layer** — a Semantic View grounding a Cortex Agent
- A **consumption layer** — where you interact through CoCo and CoWork

## Prerequisites

- A Snowflake trial account (credentials from your facilitator)
- Chrome or Edge browser
- No prior SQL or coding experience required

## Getting Started

1. **Run the setup script** — Download [`00_L100_Setup.sql`](00_L100_Setup.sql), open a Snowsight Workspace, paste it in, and click **Run All**. Takes about 2 minutes.
2. **Follow the guide** — Open [`L100_Participant_Guide.html`](L100_Participant_Guide.html) in your browser for the full step-by-step walkthrough, including a slide reference, a Snowsight tour, and sample prompts for both CoCo and CoWork.

That's it — everything else you need is inside the guide.
